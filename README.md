# Harrish - Portfolio Website

A modern, responsive portfolio website showcasing professional experience, projects, and skills.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Easy Navigation**: Smooth scrolling between sections
- **Mobile Menu**: Hamburger menu for mobile devices
- **Social Links**: Quick access to LinkedIn, GitHub, and email
- **Downloadable Resume**: Direct link to download PDF resume

## Sections

1. **Home/Hero**: Eye-catching introduction with call-to-action buttons
2. **About**: Brief introduction and background
3. **Experience**: Timeline of professional experience
4. **Projects**: Showcase of notable projects with links
5. **Skills**: Organized display of technical skills by category
6. **Contact**: Contact information and social links

## Customization

### Update Personal Information

1. **index.html**:
   - Replace "Harrish" with your name
   - Update social media links (LinkedIn, GitHub, email)
   - Add your actual contact information in the Contact section
   - Update experience details in the Experience section
   - Add your projects in the Projects section
   - Modify skills in the Skills section

2. **styles.css**:
   - Customize colors by changing CSS variables in `:root`
   - Adjust fonts, spacing, or other styling as needed

3. **Resume**:
   - Replace `Harrish___SWE_Resume.pdf` with your actual resume file
   - Update the download link in index.html if you rename the file

## How to Use

1. Open `index.html` in a web browser to view locally
2. Deploy to any web hosting service (GitHub Pages, Netlify, Vercel, etc.)

### Deploy to GitHub Pages

1. Create a new repository on GitHub
2. Push these files to the repository
3. Go to Settings > Pages
4. Select the main branch as source
5. Your site will be live at `https://yourusername.github.io/repository-name`
